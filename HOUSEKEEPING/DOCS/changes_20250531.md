## Technical Details

### Automatic Web Search Logic
The system now uses intelligent logic to determine when web search tools should be enabled:

1. **Model-Based Auto-Enablement**: All GPT-4.1 variants automatically get web search tools
2. **Step-Based Auto-Enablement**: Research steps requiring live data automatically get web search tools
3. **Manual Override**: Explicit configuration (`enable_web_search: true/false`) overrides automatic behavior
4. **Legacy Support**: Existing `web_search_queries` configuration still triggers enablement

### Decision Flow
```
Manual Override Check → Model Type Check → Step Type Check → Legacy Config Check → Default (No Web Search)
```

### Tool Implementation
- Uses OpenAI's official function calling format

- Automatic tool_choice setting
- Comprehensive tool call extraction and logging
